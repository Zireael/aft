## Safety boundary and remaining gaps

- A stat-stamped digest is cache identity, not a new independent authenticity authority: the existing installation metadata's expected SHA remains the comparison target. Legacy/mismatched LSP stamps still pay a **one-time synchronous** verification because the existing cached-directory API is synchronous. Managed new installs write stamps while hashing asynchronously. ONNX legacy verification is asynchronous.
- The daemon exposes no session-wide census of running tasks, active watches or pending detaches. Per parent decision, **unknown histories are never idle-evicted**. OpenCode 1 `session.created` and Pi `new`/`fork` mark observed lifetimes; Pi startup/reload/resume and OpenCode 2 remain unknown. A pool restart, or recreation after eviction, conservatively loses observed-history eligibility. Full reclamation of these histories requires a daemon census, not a fabricated test seam.
- Running/killing tasks, terminal-but-unACKed completions, registered/pending watches, ambiguous background outcomes, received-but-undrained nudges and pending detach work retain their carrier. A pattern ACK is not a task-terminal assertion. An unknown task needs a terminal snapshot/completion before ACK can safely release it. Unscoped ambiguous mutations retain conservatively until session close.
- Carrier teardown never deletes daemon state. Tests cover immediate wakes without another request for retained work, clean-session eviction, real-shaped queued completion replay/ACK after recreation, and bounded pending host-creation hints.
- The minimal approved Pi entrypoint hunk and OpenCode event wiring are committed separately for integration overlap. No Pi tool-registration file, absent OMP compatibility module, tool argument schema, read description, config key, lockfile or package manifest was changed.
- The rejected project-root memo and its memo-specific counter test were removed after review. The local canonical-facade reuse remains unchanged and now has filesystem-call counters for both tool-call and native-send dispatch. No ancestor watchers remain in project identity.
